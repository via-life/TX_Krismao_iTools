拉题作业流水线 · 浏览器本地处理 · 需求一内网一键上传

把 itools 平台的四个脚本搬进浏览器：图片转链接、数据聚合、多轮渲染、tlabel 格式转换。需求二至四仍在浏览器本地处理；需求一通过只监听 127.0.0.1 的本地服务使用当前电脑的内网能力上传图片。

需求一 · P0
Excel 图片转 URL
上传含内嵌图片的 xlsx，选择测试或正式环境即可一键转为内部链接并写回表格。上传功能需在项目目录双击“启动.bat”后使用。
上传文件 / 选择环境 / 写回 打开 →

数据聚合（拉题准备）
保留上传表原样，按 cid 把多轮 prompt/图片聚合成一行 JSON，写入从左往右第一个空白列（session），其它列不变。
聚合写回原表 打开 →

需求三 · P0
多轮会话渲染
把拉题结果（messages 列）像素级还原成多轮对话，支持单/双模型对照，可携带 Cookie/鉴权头加载 hunyuan 内网图片，导出 PNG。
对话可视化 / 鉴权图片 / 导出 PNG 打开 →
