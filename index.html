iTools 自动化工具集

拉题作业流水线 · 浏览器本地处理 · 需求一/三内网一键上传

把 itools 平台的四个脚本搬进浏览器：图片转链接、数据聚合、多轮渲染、tlabel 格式转换。需求二、四及需求三预览可直接使用；需求一上传、需求三截图上传和链接写回通过只监听 127.0.0.1 的本地服务完成。

🖼️
需求一 · P0
Excel 图片转 URL
上传含内嵌图片的 xlsx，选择测试或正式环境即可一键转为内部链接并写回表格。上传功能需在项目目录双击“启动.bat”后使用。
上传文件 / 选择环境 / 写回 打开 →
🧩
需求二 · P1
数据聚合（拉题准备）
保留上传表原样，按 cid 把多轮 prompt/图片聚合成一行 JSON，写入从左往右第一个空白列（session），其它列不变。
聚合写回原表 打开 →
💬
需求三 · P0
多轮会话渲染
还原单/双模型多轮对话并直接展示图片，失败时提供原图链接与灯箱查看。GitHub Pages 可预览/导出；本地可选测试或正式环境逐会话上传截图，并在原 Excel 最右侧新增 png_url 后另存新文件。
图片可视化 / PNG 导出 / 本地链接写回 打开 →
🏷️
需求四 · P1
转 tlabel jsonl
按 cid 聚合、取末轮，输出 tlabel 平台所需字段（cid / user_prompt / model_x_response / model_x_url）的 jsonl，用于 DCG / GSB，支持单双模型。
xlsx → jsonl 打开 →
